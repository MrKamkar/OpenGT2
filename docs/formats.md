# OpenGT2 Binary Formats Reference

## Confidence Levels (E0–E3)

| Level | Name | Meaning |
| --- | --- | --- |
| **E0** | Unverified / Hypothesis | Assumed or inferred without direct binary inspection. **Do not implement** without verification. |
| **E1** | Documented / External | Based on external documentation or community notes, not yet verified against local binary samples. |
| **E2** | Observed | Verified on one or more local binary samples; edge cases or variants may still exist. |
| **E3** | Verified | Confirmed across multiple samples and covered by automated parser tests / round-trip checks. |
